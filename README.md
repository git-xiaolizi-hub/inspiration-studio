# 灵感工坊 · Inspiration Studio

> 个人学习项目，仍是草稿、正在开发，**没有可用性保证**，欢迎交流。

给 AI 视频创作者用的**灵感工作台**：把零散的想法记下来 → 让模型扩成故事与脚本 → 拖出节点式工作流 → 产出图片和视频。

**纯前端 · 本地优先**：没有后端、没有账号；数据存在浏览器 IndexedDB 里，API Key 自己填、只留在本机。

**在线试用**：<https://git-xiaolizi-hub.github.io/inspiration-studio/>

---

## 它现在能做什么

### 1. 记录想法
- 文字 / 语音两种入口；语音可以转成文字，也可以只存录音
- 标签、置顶、合集、全文搜索
- 卡片网格 + 详情页；成品和它的来源素材之间有页内关系（不算云同步）

### 2. 写作台
- 左边挑素材，右边写正文，AI 只在这个上下文里回答
- 三个落笔动作：**替换正文**（会再确认一次，覆盖不可撤销）/ **插入光标处** / **追加末尾**
- 对话只发生在卡片里；改动自动落库，刷新不丢

### 3. 节点式工作流
- 画布上拖节点、连线，端口分**文本 / 图片 / 视频**三类
- 一个节点只跑一次、顺序执行；同一个上游只跑一次并复用结果
- 连线前做类型校验，成环直接报错

### 4. AI 配置（这块做得最细）
- 一个厂商下可以有**多条连接**；一条连接一把 Key；一把 Key 可以挂多个模型（文本 / 视觉 / 生图 / 视频 / 音频）
- **计费方式**四种：中转站（分组倍率）、国内按量、官方订阅、国外按量（按实时汇率）
- **推荐配置**：内置三组常用搭配（DeepSeek 官方 / 火山方舟 / 灵绘中转）。已经配过的会自动回填并标「已配置」，只补你没填的
- **选型指南**：按用途（写作 / 生图 / 视频 / 音频）说明该选哪个模型、大概什么价位
- 每个模型可以单独「测试」连通性，也可以按 Key「拉取」真实模型列表

### 5. 生图 / 生视频
- 内置几家厂商的调用适配（豆包 seedream / seedance、gpt-image、qwen-image 等）
- 生成前会给一次花费提醒（官方价 × 倍率，口径见下）

### 6. 数据在自己手上
- 一键导出 zip（记录 / 媒体 / 配置 / 价格表），可以勾选是否带上 API Key
- 导入支持「合并」或「覆盖」
- 四套主题，随手换

## 还没做 / 现在别指望的地方

- **写作台和节点式工作流的效果还很粗**：流程能跑通，离“好用”差得远
- 3D 导入、音频生成、剪辑软件对接：只有路线图，没实现
- 桌面版（Tauri / Electron）还没打包；网页版不含本地语音模型（权重 78MB，仓库不带权重文件）
- 部分厂商（火山方舟、多数中转站）会被浏览器 CORS 拦住，网页端直连会失败

## 价格是怎么算的

国外模型的官方价按**中转站「¥1 = $1」**的口径折成人民币，所以界面上只有「倍率」一个旋钮：

| 场景 | 倍率填什么 |
|---|---|
| 中转站 | 该站的分组倍率（常见 0.1 ~ 1.1） |
| 国内模型按量 | 1（官方价本来就是元） |
| 官方包月订阅 | 0（单次边际成本≈0） |
| 国外官方按量 | 实时汇率（自动取，可手改） |

估算只用于生成前提醒，不承诺准确——中转站的分组与计价规则各家不同。

## 技术栈

React 18 + TypeScript + Vite；数据用 Dexie（IndexedDB）；画布与工作流用 xyflow；语音用 transformers.js 跑本地 whisper；测试用 Vitest + Testing Library。

```bash
npm install
npm run dev       # http://127.0.0.1:5173
npm run test      # 约 1200 条单元与组件测试
npm run build     # 类型检查 + 生产构建
```

